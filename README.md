# 大肥鱼自动保存表情包（xhs-memes）

自动刷小红书、按关键词搜「表情包」，把图裁到合适尺寸后**直接存进大肥鱼的表情包**（QQ 收藏表情）。

模块做四件事：

- **看**：专用浏览器 + 扫码登录，关键词一个个轮着搜，一篇笔记打开后停 2~6 秒再翻下一篇；
- **存**：只存图，不点赞、不评论、不转发；
- **停**：一轮最多几张、一轮最长多久、一天几轮、两轮之间隔多久，都能在面板里调；
- **防重**：同一篇笔记、同一个图片地址、同一张原图，三道闸全挡住。


## 用起来

面板（插件 Web 界面 → 模块 → 小红书表情包）就三块：

1. **收表情**：打开总开关 → 点「现在收一轮」。也可以点某个词的快捷按钮（表情包 / 抽象表情包 /
   沙雕表情包 / 猫猫表情包 / 熊猫头），或者贴一篇笔记链接只扒那一篇（最多 99 张）。
2. **最近收的**：缩略图墙，点 × 单张删（QQ 收藏里那张一起删）。
3. **设置和登录**：搜索词、一轮几张、一轮多久、一天几轮、间隔、每篇停留几秒、新号保护、
   裁剪边长、浏览器路径；没登录就在这里扫码。

聊天里也能用：`xhs_collect_memes`（去收一轮）／`xhs_collect_from_link`（扒这一篇）／
`xhs_meme_status`（查进度）。三个都只听主人的。

## 安全口径

- 必须登录才动。登录判据是浏览器里的 `web_session` cookie（页面 `document.cookie` 读不到它，
  所以走 CDP 全量读），userId 取侧栏「我」链接里的 24 位主页 id，昵称顺手从自己主页标题拿。
- **登录态不会瞎报「没登录」**：浏览器开着就实时查，关着就用上次的结果（面板上标「上次查到的」）；
  点「检查登录」会先把浏览器拉起来再查，15 秒内查过就复用，不反复戳。
- 已经登录时点「扫码登录」不会弹二维码，直接告诉你「已登录：昵称」。
- 登上了会自动解除「因为没登录而暂停」的状态，不用等到第二天。
- 没登录 / 要验证码就停，当天不再动手，还会在 QQ 上跟主人说一声并附截图。
- **存够就停**：一轮最多存几张（默认 20，新号前 3 天减半）。
- **到点收手**：一轮最长跑多久（默认 15 分钟）。
- **节奏**：一天最多几轮（默认 4）+ 两轮间隔（默认 6 小时），自动跑按这个排。
- 刚扫码登录后 5 分钟内不自动开刷（首登立刻猛刷最容易被判异常）。
- 每篇笔记停留 2~6 秒随机，篇与篇之间再小睡一下，像人看完才翻下一张。
- 单篇 404 只是这篇不行，跳过继续；同一篇连续两次打不开就再也不试（免得每轮都撞）。
  只有「验证 / 频繁 / 异常」这类字眼才整天收手。

## 去重（三道闸）

1. **帖子**：`seenNotes` 记住刷过的笔记 id，搜索/推荐流都会跳过，翻到底会继续往下滚找新的。
2. **图片地址**：`seenUrls` 记住下过的 URL，同一张图不会再下一次。
3. **内容**：原图 md5 记进 `memes` 账本；表情库自己还有一层 md5 去重（裁方后 md5 变了，所以
   账本用原图 md5），已经有的不算新存也不会重复收藏。

## 存进去长什么样

- 长边默认 480（可调 120~520），因为 QQ 收藏表情要求边长 ≤520、长宽比 0.75~1.33。
- 默认只把比例「夹」进合格范围，尽量少裁内容；想一律正方形就打开「裁成正方形」。
- 名字取笔记标题（最多 12 字），一篇多图会带序号：`精神状态全世界倒数第一3`。
- 直接进 QQ 收藏表情库（走内置表情包模块的 `addFromBuffer` → OneBot `add_custom_face`）。

## 数据放在哪

- 采集状态：`~/.dsh/plugins-data/aurabot/modules-data/xhs-memes/state.json`
  （`items` / `memes` / `seenNotes` / `seenUrls` / 统计 / 暂停标记；早期版本写在 `aurabot/store.json`，会自动搬过来）
- 浏览器资料目录：`~/.dsh/plugins-data/aurabot/xhs-memes/edge-profile`（扫码登录的 cookie 在这）
- 表情本体：`~/.dsh/plugins-data/aurabot/stickers/`

## 面板接口（挂在 `/aurabot/api/ext/xhs-memes/` 下）

`/state` `/recent` `/run` `/run-link` `/remove` `/account` `/login` `/login/status` `/window`

## 文件

- `index.mjs`：模块入口。默认设置、工具、面板路由、裁方 + 存库的注入。
- `lib/collect.mjs`：采集主流程（ready 门禁 / 轮次规则 / harvest 一篇篇收 / finish 收尾排期 / tick 定时）。
- `lib/site.mjs`：小红书页面 DOM 解析（`feed` 推荐流、`search` 搜索结果、`readNote` 读一篇）。
- `lib/browser.mjs`：CDP 专用浏览器（独立资料目录、自带退避重试、挑标签页时躲开 edge:// 内部页）。
- `lib/ego.mjs`：可选后端，能接上宿主已经开着的共享浏览器实例就接，接不上就自己拉一个，互不影响。
- `lib/imaging.mjs`：sharp 裁方转 JPEG。
- `lib/memes.mjs`：纯函数（词清洗、挑图、起名、md5 账本）。
- `lib/vision.mjs`：下载图片。
- `panel.js`：面板。
- `test/run.mjs`：离线自测（假 site / 假下载 / 假表情库），`node test/run.mjs`。
